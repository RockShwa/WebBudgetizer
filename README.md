# WebBudgetizer - A Budgeting Application

## Project Description

This application is designed to allow the user to upload and categorize transactions, all while tracking their spending and savings over time. The user can also create budget goals and manage their income. This application utilizes a local MSSQL database while it's in development. 

## Starting the Server

To start the development server simply run the following command in the project folder in your terminal:

```sh
bun run dev

# or start the server and open the app in a new browser tab
npm run dev -- --open
```
This application utilizes Bun instead of Node.js. Bun is a runtime that prioritizes developer speed for smaller applications.
